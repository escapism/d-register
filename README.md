## Dレジ
主に同人誌即売会での利用を想定したレジアプリ（PWA）です。  
データはIndexedDBでデバイス側に保存されます。
  
[GitHub Pages で公開しています](https://escapism.github.io/d-register/)

### 特徴
- **PWA**: ホーム画面に追加（インストール）することで、ネイティブアプリのように使用できます。
- **通信不要（オフライン対応）**: データはすべて使用者のデバイス上に保存されます。一度読み込めばオフラインでも動くので、電波の悪い会場でも使用できます。
- **プライバシー重視**: 頒布物情報や売上情報がサーバーへ送信されることはありません。<sup>※</sup>

<small>※利用状況把握のため、Google Analytics を使用してアクセスログを収集していますが、これはアプリ内のデータや個人を特定できるような情報は含みません。</small>

### 主な機能
- **レジ機能**: 合計金額の即時計算、お釣り計算。
- **頒布物管理**: 画像付きの頒布物登録・編集。
- **売上管理**: 頒布数、金額の確認、精算履歴確認・取消、CSV書き出し。
- **バックアップ機能**: バックアップ用のJSONエクスポート・インポート機能。
