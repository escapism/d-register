## Dレジ
主に同人誌即売会での利用を想定したレジアプリ（PWA）です。  
データはIndexedDBでデバイス側に保存されます。
  
[GitHub Pages で公開しています](https://escapism.github.io/d-register/)

<a href="https://escapism.github.io/d-register/"><img src="https://github.com/user-attachments/assets/3205a9fc-c11b-44c5-a154-1de290d812fa" width="240" alt=""></a>

### 特徴
- **PWA**: ホーム画面に追加（インストール）することで、ネイティブアプリのように使用できます。
- **オフライン対応**: データはすべて使用者のデバイス上（ブラウザ）に保存されます。一度読み込めばオフラインでも動くので、電波の悪い会場でも使用できます。
- **プライバシー重視**: 頒布物情報や売上情報がサーバーへ送信されることはありません。<sup>*1</sup>

*1 利用状況の把握のため、Google Analytics を使用して情報の収集・分析を行っています。これらの情報には、アプリ内に保存されたデータや、個人を特定できるような情報は一切含みません。

### 主な機能
- **レジ機能**: 合計金額の即時計算、お釣り計算、年齢確認。
- **頒布物管理**: 画像付きの頒布物登録・編集、カテゴリー・ジャンル分け。
- **売上管理**: 頒布数、金額の確認、精算履歴確認・取消、CSV書き出し。
- **バックアップ機能**: バックアップ用のJSONエクスポート・インポート機能。

#### 🔧専用ツール
パソコンなどの大きな画面で一括で頒布物を編集したい方のために、外部ツール「[Dレジエディター](https://github.com/escapism/d-regi-editor)」を用意しています。  
Dレジで書き出したJSONファイルを読み込んで、表計算ライクな画面で編集ができます。
